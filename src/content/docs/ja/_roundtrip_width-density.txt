Understanding the width (w) and density (x) descriptors in `srcset`. Use examples, using Markdown.

> `srcset` is an HTML attribute that allows developers to provide multiple image sources with different resolutions and pixel densities, enabling the browser to select the appropriate image based on the display characteristics of the device. The `srcset` attribute specifies images using `URL` and `w` or `x` descriptors.

## Width (`w`) Descriptor

> The `w` descriptor is used to specify the width of an image in pixels. It is used when you need to provide the browser with the dimensions of the image so it can select an image suitable for the available screen space.

> The syntax to use the `w` descriptor in `srcset` is as follows:

```html
<img src="small.jpg"
  srcset="small.jpg 500w,
          medium.jpg 1000w,
          large.jpg 2000w"
  alt="Example Image">
```

> In the example above, three images along with their widths (in pixels) are provided to the browser. The browser selects the image with the width closest to the available screen space.

## Density (`x`) Descriptor

> The `x` descriptor is used to specify the pixel density of an image. This is the ratio of physical pixels to CSS pixels. It is used when you wish to provide different versions of the same image with different pixel densities to the browser.

> The syntax to use the `x` descriptor in `srcset` is as follows:

```html
<img src="small.jpg"
  srcset="small.jpg 1x,
          medium.jpg 2x,
          large.jpg 3x"
  alt="Example Image">
```

> In the example above, three images along with their pixel densities are provided to the browser. The browser selects the image with the pixel density closest to the screen of the device.

> Note that `w` and `x` descriptors can be used together in the same `srcset` attribute to provide the browser with more options to choose from.
