Srcset with density descriptors provides a simple and effective way to deliver the most suitable images to each user’s device, enhancing performance and user experience. This guide introduces the basics of srcset with density descriptors and provides helpful markup examples.

## What Are Density Descriptors and Srcset?

Srcset is an HTML attribute designed to allow a single `<img>` element to specify multiple image sources. Density descriptors (`x`) are used in conjunction with srcset to provide images of different resolutions based on the user's display pixel density.

## When to Use Density Descriptors and Srcset

Using density descriptors and srcset is particularly useful in the following scenarios:
1. When you want to display high-resolution images on high-DPI displays (e.g., Retina displays) while providing lower-resolution images for standard displays.
2. When you want to improve page performance by delivering the optimal image size for each user's device.

## How to Implement Density Descriptors and Srcset

To use density descriptors and srcset, follow these steps:
1. Prepare your images in different resolutions.
2. Add the `srcset` attribute to the `<img>` element, including the image sources and corresponding density descriptors.
3. Optionally, add the `sizes` attribute to specify the size of the image as it appears on the screen.

### Example of Markup

Below is an example of implementing markup using density descriptors and srcset:

```html
<img src="example-image-1x.jpg"
     srcset="example-image-1x.jpg 1x, example-image-2x.jpg 2x, example-image-3x.jpg 3x"
     alt="An example image">
```

This markup example includes:
- **src**: The default image source displayed if the browser does not support srcset.
- **srcset**: A list of image sources and their density descriptors (1x, 2x, 3x). The browser chooses the optimal image based on the user’s display.
- **alt**: Text that describes the image for accessibility purposes.

That's it! By implementing srcset and density descriptors, you have enhanced the performance and user experience of your website.
