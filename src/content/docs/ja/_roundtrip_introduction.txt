**An efficient and opinionated image guide for 2023**

Check the sidebar for more details. This is a quick reference for upgrading `<img>` tags to cater to the different sizes and pixel densities of modern devices. [Pixels != Pixels](/ja/pixels-not-pixels) is something you should know, and `devicePixelRatio` is often closer to 3.875 than 1:1. Modern smartphones disguise a width of 320-428px for readability (in CSS pixels) but have many device pixels per one CSS pixel.

> If the size of the image never changes, no matter how narrow you make the browser window, you should use [density descriptors](/ja/density-descriptors) instead. This is often suitable for logos, icons, and buttons.

Do you know your [breakpoints](/ja/breakpoints)? You will need these numbers to fine-tune the solution below. And you will need at least the breakpoint where the growth of the main content area stops.

### The Easy Way

```html

<img src="img.jpg?w=480" 
        srcset="img.jpg?format=webp&w=480 480w, 
                img.jpg?format=webp&w=800 800w, 
                img.jpg?format=webp&w=1200 1200w, 
                img.jpg?format=webp&w=1600 1600w, 
                img.jpg?format=webp&w=2000 2000w"

        sizes="(max-width: 700px) 100vw, 800px" alt="Dog riding a bicycle" />

<!-- Assuming you have set the breakpoint at 700px.
      Below this viewport width, the image takes 100% of the width, but as the viewport gets larger,
      it is assumed the image is constrained to 800 CSS pixels. -->

<!-- Assuming you use an RIAPI-compliant image server, such as Imageflow.
     Real-time image variant creation is essential for developer peace of mind. -->
```
