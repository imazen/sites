### 背景

小屏幕和大显示器需要不同的布局。为了 `srcset` 和 `sizes` 的目的，我们需要知道布局在哪个点会发生变化。

网页开发者必须决定在小屏幕上要缩小、隐藏或重新定位的内容——或者更常见地，在大屏幕上要扩展、展示或添加的内容。而他们掌握的相关信息非常少。用户是在平板上还是在手机的横屏模式下——或者只是一个小的浏览器窗口？

我们必须选择一个任意的视口宽度来改变布局。这被称为一个**断点**。这是一个任意的 CSS 像素（[而非设备像素](/zh/pixels-not-pixels)）。Polypane 有一篇[很棒的文章](https://polypane.app/blog/the-breakpoints-we-tested-in-2021-and-the-ones-to-test-in-2022/#the-breakpoints-to-develop-on-in-2023)关于常用的断点。

一些图像（比如标志、图标或者按钮）可能不会受到这些断点引发的布局变化的影响（对于这些可以使用[srcset 密度描述符](/zh/density-descriptors)）。

主要内容图像将被它们容器的大小所限制。通常，一个页面的主要内容区域在最大屏幕上会被限制在一个特定的宽度上，即 `max-width`，但在小屏幕上，主要内容区域会占满整个视口。

如果你在某些断点有超过一列的内容，计算有效的尺寸规则会变得更复杂，因为图像占用的视口宽度百分比会发生变化。

### 简单方法

话虽如此，别想得太复杂。以下近似方法可能会很适合：

1. 主要列（或图像的容器）停止增长的大小是多少？在此视口宽度范围内，我们可以使用 `100vw` 作为图像的 `sizes` 属性，表示图像占据视口宽度的 100%。  
2. 该容器能达到的最大宽度是多少？我们可以将其设置为其他所有内容的固定 `width`。

如果你对1的回答是700px， 对2的回答是800px，你可以使用以下 `sizes` 属性：

```html
<!-- 这些是CSS像素，而不是设备像素或图像像素。 -->
<img [...] sizes="(max-width: 700px) 100vw, 800px"  />
```

> 你可能认为浏览器可以根据CSS很好地处理所有这些计算。不幸的是，浏览器在样式表下载之前急于选择图像URL。所以我们不得不自己进行计算，如果做得不完美，那也是它们应得的。
