**An Efficient and Insightful 2023 Image Guide**

Refer to the sidebar for more details. This is a quick reference suitable for upgrading `<img>` tags to accommodate various sizes and pixel densities on modern devices. You should [know that pixels != pixels](/en/pixels-not-pixels), and `devicePixelRatio` is more likely to be around 3.875 rather than a 1:1 ratio. Modern phones pretend to have a width of 320-428px for readability (in CSS pixels), but there are many device pixels per CSS pixel.

> If your image size never changes, no matter how you resize the browser window’s width, you should use [density descriptors](/en/density-descriptors). This typically applies to logos, icons, and buttons.

Do you know your [breakpoints](/en/breakpoints)? You need these figures to fine-tune the solution below—at the very least, identify the viewport width breakpoint where your main content area stops expanding.

### Simple Method

```html

<img src="img.jpg?w=480" 
        srcset="img.jpg?format=webp&w=480 480w, 
                img.jpg?format=webp&w=800 800w, 
                img.jpg?format=webp&w=1200 1200w, 
                img.jpg?format=webp&w=1600 1600w, 
                img.jpg?format=webp&w=2000 2000w"

        sizes="(max-width: 700px) 100vw, 800px" alt="dog cycling" />

<!-- We're assuming you have a breakpoint at 700px. 
      At that viewport width, this image occupies 100% of the width, but when the viewport is larger, the image is limited to 800 CSS pixels -->

<!-- This assumes you are using an image server compliant with RIAPI, such as Imageflow.
     Instantly generating image variants is crucial for developers' sanity. -->
```
