The general procedure for creating an image gallery on a website is as follows:

1. Create a new HTML file for the image gallery. You can name it something like "gallery.html."
2. Add the HTML structure to the file. This typically includes the head section with the title and necessary CSS stylesheets, and the body section where you add the actual gallery.
3. Use the `<div>` tag to create a container for the gallery. Assign an ID or class to allow for style modification later.
4. Within the container, use the `<img>` tag to add individual image elements. Set the path or URL of the image file in the source attribute and add alternative text or captions if needed.
5. Style the gallery with CSS. You can use properties like display, width, height, margin, padding, and border to control the layout and appearance.

Here is a sample code for creating a simple image gallery:

```html
<!DOCTYPE html>
<html>
<head>
	<title>My Image Gallery</title>
	<style>
		.gallery {
			display: flex;
			flex-wrap: wrap;
			justify-content: center;
		}
		.gallery img {
			width: 300px;
			height: 200px;
			margin: 10px;
			object-fit: cover; /* Ensures aspect ratios are maintained even if the images are not the same size */
			border: 2px solid black;
		}
	</style>
</head>
<body>
	<div class="gallery">
		<img src="image1.jpg" alt="Image 1">
		<img src="image2.jpg" alt="Image 2">
		<img src="image3.jpg" alt="Image 3">
		<img src="image4.jpg" alt="Image 4">
		<img src="image5.jpg" alt="Image 5">
		<img src="image6.jpg" alt="Image 6">
	</div>
</body>
</html>
```

In this example, the gallery container has a class of "gallery," and is styled with flexbox to arrange the images in a grid. Each image is set with a width of 300px, height of 200px, a margin of 10px, and a 2px solid black border. The object-fit property is used to ensure that aspect ratios are maintained even if the images are not the same size.

You can customize this code to suit your specific needs and design preferences.
